# Qt Designer GUI (Python)

Ein grafisches Benutzerinterface (GUI), das mit dem **Qt Designer** erstellt wurde. Dieses Projekt dient als Basis für eine Python-Anwendung mit PyQt oder PySide.

## 🚀 Features

Die Benutzeroberfläche (`MeinFormular`) enthält:
* **Interaktive Buttons:**
    * `Beenden`: Schließt das Anwendungsfenster (Slot: `close()`).
    * `Maximieren`: Vergrößert das Fenster auf Vollbild (Slot: `showMaximized()`).
* **UI-Komponenten:** Ein zentrales Label mit dem Text "Hallo Welt".
* **Layout:** Kompaktes Design mit einer Startgröße von 250x100 Pixeln.

## 🛠 Technologien

* **XML / UI:** Qt User Interface File (Version 4.0)
* **Tool:** Qt Designer
* **Kompatibilität:** Funktioniert mit `PyQt5`, `PyQt6`, `PySide2` oder `PySide6`.
